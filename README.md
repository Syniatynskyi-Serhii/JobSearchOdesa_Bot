# JobSearchOdesa_Bot
Telegram-бот для автоматичного збору та моніторингу нових вакансій із сайтів з пошуку роботи.

## 🤖 Бот для моніторингу вакансій
Цей Telegram-бот автоматично збирає свіжі вакансії за заданими ключовими словами з популярних сайтів роботи та надсилає їх у приватні повідомлення.

## 🚀 Функціонал
- Парсинг сайтів (наприклад, Work.ua, Robota.ua, Djinni) кожні 30 хвилин.
- Фільтрація вакансій за містом та ключовими словами (наприклад, "Python", "QA").
- Сповіщення лише автора бота (захист за Telegram ID).

## 🛠️ Налаштування та запуск

1. Клонуйте репозиторій:
```bash
git clone https://github.com
```

2. Створіть файл `.env` у корені проєкту та додайте ваші дані:
```ini
BOT_TOKEN=ваш_токен_від_botfather
ADMIN_ID=ваш_telegram_id
```

3. Встановіть залежності та запустіть бота.
